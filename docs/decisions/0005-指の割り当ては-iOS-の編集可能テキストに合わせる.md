# 0005. 指の割り当ては iOS の編集可能テキストに合わせる

## 決めたこと

| 操作 | 結果 |
| --- | --- |
| 叩く | キャレットを置く |
| 続けて 2 回 / 3 回 | 単語 / 段落。掴んだまま引きずれば伸びる |
| 長押し | そのままキャレットを引き回す |
| なぞる | スクロール |

## 背景

[0007](0007-選択も自前で描く.md) で選択を自前にしたので、
指のジェスチャも全部こちらで決めることになった。
**指のドラッグはスクロールに使う**ので、選びたいという意思を拾う口が限られる。

## なぜ

iOS の編集可能なテキストがこの割り当てだから。
一度は長押しを単語選択にしていたが、それは**閲覧テキスト側の作法**だった。

## 代償

- 合成マウスイベントを touchend で止めているので、`event.detail` のダブルクリック判定が使えない。
  続けて叩いた回数は自前で数えている (300ms / 24px)
- 引きずっている間は `touchmove` を断ってパンを止める。
  `touch-action` は指を置いた時点で決まるので、始まったあとに止める口はこれしかない

## 比較対象

| | 捨てた理由 |
| --- | --- |
| 長押しで単語選択 (閲覧テキストの作法) | 編集できるテキストでは、iOS は長押しでキャレットを動かす |
| 指のドラッグを選択に使う | スクロールが出来なくなる |
| 2 本指のジェスチャ | iOS がピンチを優先することがあり、取りこぼす端末が出る |
