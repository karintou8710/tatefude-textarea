# 0002. 入力は隠し入力で受ける

## 決めたこと

1x1 で `opacity: 0` の `<textarea>` に focus を置き、入力・IME・クリップボードをそこで受ける。

## 背景

[0001](0001-縦書きテキストエリアのアーキテクチャ.md) で本文を非編集要素にしたので、
キー入力も変換も自分では受け取れない。どこかにブラウザの入力経路を借りる必要がある。

## なぜ

IME とクリップボードは自前で作れるものではない。
借りられる口が、実質これしかない。

## 代償

- focus が本文と別の要素にある。**iOS ではこれが原因でキーボードが閉じる** → [../research/ios.md](../research/ios.md)
- **本文のネイティブ選択が始まらなくなる** → [0007](0007-選択も自前で描く.md)
- 支援技術から見て「値が空の 1x1 textarea」になる。a11y が壊れている
- 候補ウィンドウの位置を合わせるため、キャレットを追いかけて要素を動かし続ける

## 比較対象

| | 捨てた理由 |
| --- | --- |
