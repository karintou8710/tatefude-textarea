# 0003. キャレットを自前で描く

## 決めたこと

キャレットは自前の要素で描く。点滅も位置も自分で持つ。

## 背景

本文は非編集要素なので、そもそもキャレットが出ない。
出せたとしても、Safari は縦書きのキャレットを **Blink が列幅いっぱいに引くところ、1/3 ほどの短い線**で描く
→ [../research/textarea.md](../research/textarea.md)

## なぜ

描かなければ何も出ない。任せられる相手がいない。

## 代償

- 行送りを実測しないと、キャレットが行番号に比例して字から離れていく
  (Safari が `line-height` を整数に丸めるため → [../research/mac.md](../research/mac.md))
- 変換中の表示と、候補ウィンドウの位置合わせも自分の仕事になる

## 比較対象

| | 捨てた理由 |
| --- | --- |
| ブラウザに描かせる | 非編集要素にキャレットは無い。選択肢として成立しない |
| `contenteditable` にして任せる | → [0001](0001-縦書きテキストエリアのアーキテクチャ.md) |
