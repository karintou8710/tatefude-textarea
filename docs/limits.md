# いま出来ないこと

## 原理的に無理

- **OS の編集メニューを出す。** 呼び出す API が無い。自前のメニューで代用する
- **「調べる」「翻訳」「置き換え」「テキストをスキャン」。** OS 側の機能なので手が届かない
- **スペースキー長押しのトラックパッド化。** ソフトキーボードの操作はページに届かない
- **アプリ間のドラッグ&ドロップ**

## 作れば出来るが、まだ無い

- **ルーペ。** 掴んでいる間だけ複製を切り抜いて拡大すればできる → [decisions/0007](decisions/0007-選択も自前で描く.md)
- **選択のドラッグ&ドロップ**（エディタの中だけなら可能）
- **キャレットだけのときにメニューを出す**（iOS はキャレットを叩くと出る）

## 壊れている

- **a11y。** 支援技術から見えるのは「テキストを持った div」と「値が空の 1x1 textarea」。
  隠し入力に value と選択を同期させれば直せるが、IME を検出する仕組みごと作り直すことになる
- **Firefox。** `setPointerCapture` が合成イベントの id を拒否する (`NotFoundError`)。未対応

## 条件つきで動く

- **ペースト。** https か localhost でないと `navigator.clipboard` が無い。
  読めるときも iOS は OS の確認タップが 1 回入る。書き込みは `execCommand` に落とせる
- **つまみ。** dom 経路だけ → [decisions/0006](decisions/0006-つまみは-dom-経路だけに持たせる.md)
