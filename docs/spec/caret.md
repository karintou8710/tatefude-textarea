# 選択とキャレット

## どちらの行に着けるか

折り返しの境目は、前の行の末尾と次の行の頭が同じ位置になる。

| 着き方 | どちら |
| --- | --- |
| 字を送って着いた | 次の行の頭。行き帰りとも |
| 行末へ飛んだ | 前の行の末尾 |
| 行の外をクリックした | クリックした行の側 |
| 改行の直後 | 必ず次の行の頭 |

## 出す / 出さない

| いつ | キャレット | 選択 | ハンドル |
| --- | --- | --- | --- |
| focus が無い | 出さない | `selectionInactive` で出す | 出さない |
| 選択が伸びている | 出さない | 出す | 指で触ったときだけ |
| 変換中 | 出す | 出さない | 出さない |

## 点滅

| | |
| --- | --- |
| 間隔 | 既定 530ms。`caretBlinkInterval` で変える |
| `0` | 点滅しない |
| 打つ / 動かす | 出た状態から数え直す |
| focus が無い | 止める |

## 太さ

1 CSS px。字の大きさに比例しない。
