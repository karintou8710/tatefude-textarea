# スクロール

**スクロールするのはブロック方向だけ**。インライン方向はレイアウトが収まる。
値は読み進んだ距離で、向きに依らず 0 以上。

## 動かすもの

| | |
| --- | --- |
| ホイール | 自前で受ける。縦書きは下へ回すと左へ読み進む |
| 指のパン | ブラウザに任せる。選択をドラッグしている間は止める |
| キャレット | 打つ・動かすたびに画面へ入れる |
| `scrollOffset` | 外から読み書きする |

## キャレットを画面に入れるもの

**いま指した一点があるときだけ入れる。**決めるのは編集操作の側で、スクロールさせるのは
繋ぐ側 (`Result.scrollIntoView`)。

| 入れる | 入れない |
| --- | --- |
| 打つ・消す・貼る・変換 | **全選択** — 選択全体が意味で、端はたまたま |
| 矢印・`Home`/`End`・`PageUp`/`PageDown` | **undo / redo** — 戻した結果で、指した場所ではない |
| `Shift` + 移動、ドラッグ、ハンドル | **`commands.setValue` / `setSelection`** — 外から渡された場所 |
| クリック・タップ | focus / blur、CSS の読み直し |

ネイティブの `<textarea>` を測って合わせた。

- 上限はレイアウトの長さから見えている長さを引いたもの。範囲外は丸める
- スクロールしきっているときのホイールはページに渡す
- スクロールバーはブラウザのもの

## コンテナが変わったとき

スマホでキーボードが出入りするとコンテナが縮み、縦書きなら行の長さごと組み直る。
読んでいた場所を見失わないように、キャレットの居場所を控えておく。

| いつ | 何をする |
| --- | --- |
| 描き直すたび | キャレットが画面のどこに居るかを控える |
| コンテナが変わった | 控えた場所へキャレットを戻す |
| そのあと focus があれば | キャレットを画面に入れる |
| focus が無ければ | 戻すだけ。キャレットは追わない |

控えを捨てるのは、**読み手が自分でスクロールしたとき**。ホイールを回した / 指で触り直した /
外から `scrollOffset` を書いた / キャレットが別の場所へ動いた。

## エンジン差

`vertical-rl` の `scrollLeft` は Blink が負、WebKit が正へ動く。距離に均して扱う。
