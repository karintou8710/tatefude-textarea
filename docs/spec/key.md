# キー

縦書きのとき。横書きでは `↑↓` と `←→` が入れ替わる。

**矢印の向きは画面に合わせ、修飾キーはその OS のネイティブに合わせる。**
語・段落へ動くのが macOS では `⌥`、それ以外では `Ctrl`。
端まで飛ぶのは macOS が `⌘` + 矢印、それ以外は `Home` / `End`。

## 移動

| 動き | macOS | それ以外 |
| --- | --- | --- |
| 1 文字進む / 戻る | `↓` `↑` | ← 同じ |
| 次の行 / 前の行 | `←` `→` | ← 同じ |
| 単語ぶん | `⌥` + `↓` `↑` | `Ctrl` + `↓` `↑` |
| 次の段落の末 / 前の段落の頭 | `⌥` + `←` `→` | `Ctrl` + `←` `→` |
| 行末 / 行頭 | `⌘` + `↓` `↑` | `End` `Home` |
| 文末 / 文頭 | `⌘` + `←` `→` | `Ctrl` + `End` `Home` |
| 1 画面ぶん行を移る | `PageDown` `PageUp` | ← 同じ |
| 選択を伸ばす | `Shift` + 上記 | ← 同じ |

- `End` `Home` はどちらの OS でも行末 / 行頭
- その OS で割り当ての無い修飾を足した矢印は受け持たない
  (Windows の `Alt` + `←` はブラウザの戻る、macOS の `Ctrl` + `←` は操作スペースの切り替え)
- 行を移るときは、元いたインライン方向の位置を保つ
- 選択がある状態のインライン方向の移動は、進まずに選んだ端へ畳む
- 端で動けなかったインライン方向の移動は、行を移るときの狙いを消さない

## 編集

| 動き | macOS | それ以外 |
| --- | --- | --- |
| 選択を置き換えて入れる | 文字 | ← 同じ |
| 改行 | `Enter` | ← 同じ |
| 手前 / 先を 1 文字消す | `Backspace` `Delete` | ← 同じ |
| 単語ぶん消す | `⌥` + `Backspace` `Delete` | `Ctrl` + `Backspace` `Delete` |
| 全選択 | `⌘` + `A` | `Ctrl` + `A` |
| 取り消す | `⌘` + `Z` | `Ctrl` + `Z` |
| やり直す | `⌘` + `⇧Z` / `Y` | `Ctrl` + `⇧Z` / `Y` |

- 絵文字や異体字は、組み合わさっていてもまとめて 1 文字として扱う
- 全選択・取り消し・やり直しは `⌘` でも `Ctrl` でも受ける
- 割り当ての無いキーは受け持たない
- 打つ・消すは 700ms 以内の連続をまとめて 1 回で戻す。キャレットを動かすと切れる
