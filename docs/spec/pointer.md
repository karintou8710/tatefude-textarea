# マウスと指

## マウス

| 操作 | 動き |
| --- | --- |
| クリック | そこにキャレットを置く。掴んだままドラッグすると伸びる |
| `Shift` + クリック | 掴んだ側を置いたまま伸ばす |
| ダブルクリック | 単語を選ぶ。そのままドラッグすれば単語ずつ伸びる |
| トリプルクリック | 段落を選ぶ |
| ホイール | ブロック方向にスクロールする (縦書きは下へ回すと左へ進む) |

- クリックした時点で指のハンドルは引っ込める
- 順番は 測る → 置く → focus

## 指

| 操作 | 動き |
| --- | --- |
| タップ | そこにキャレットを置き、ハンドルを出す |
| ダブルタップ | 単語を選ぶ。掴んだままドラッグすれば伸びる |
| トリプルタップ | 段落を選ぶ |
| 長押し (500ms) | 掴んでキャレットを引き回す。離しても置き直さない |
| スワイプ | スクロール。キャレットは動かさない |
| ハンドルを引く | その端だけ動く |

- 8px 動いたらスクロール。タップした扱いも長押しもやめる
- 続けてタップしたと見るのは 300ms 以内かつ 24px 以内
- focus を入れるのは離してから
- ハンドルが出るのは選択があるときだけ。dom 経路のみ

## クリックした場所が本文に当たらないとき

キャレットを動かさない。
