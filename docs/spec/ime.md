# 変換

**確定するまで本文に入れない**。預かって表示にだけ混ぜる。

| 出来事 | 動き |
| --- | --- |
| 開始 | 選択があれば先に消す。その位置で預かり始める |
| 更新 | 預かっている字を差し替える。本文は変わらない |
| 確定 | 預かった位置へ確定文字列を入れる |
| 取り消し | 預かった字を捨てる。本文は変わらない |

- 変換中の字には下線。縦書きなら字の左、横書きなら下
- IME がいま対象にしている文節だけ線が太い (2px / 1px)
- 変換中は選択もハンドルも出さない
- 候補ウィンドウはキャレットの脇に出す
- 確定文字列が空でも、預かった字と下線は消す

前後の文字列は IME に渡せていない → [../limits.md](../limits.md)
