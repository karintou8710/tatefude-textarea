# 変換

**変換中の字も本文に入る。**確定していないことは `state.composing` で分かる
→ [decisions/0009](../decisions/0009-変換中の字も本文に入れる.md)

| 出来事 | 動き |
| --- | --- |
| 開始 | 選択があれば先に消す。その位置から変換の範囲が始まる |
| 更新 | 範囲の中身を新しい字に差し替える |
| 確定 | 範囲を確定した字に差し替えて、範囲を閉じる |
| 取り消し | 範囲を空にする。変換の前の本文に戻る |

- 変換中の字には下線。縦書きなら字の左、横書きなら下
- IME がいま対象にしている文節だけ線が太い (2px / 1px)
- キャレットは文節の末尾に乗る
- 変換中は選択もハンドルも出さない
- 候補ウィンドウはキャレットの脇に出す
- 1 変換は 1 つの undo にまとまる (700ms のまとまりに乗る)
- `onChange` は変換中も飛ぶ。native の `<textarea>` も `input` を飛ばす

前後の文字列は IME に渡せていない → [../limits.md](../limits.md)
